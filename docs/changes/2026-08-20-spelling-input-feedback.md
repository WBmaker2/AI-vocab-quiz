# 철자 완성 입력창·오답 피드백 개선

## 변경 목적

긴 영어 단어를 입력할 때 입력창이 좁아지는 불편을 줄이고, 학생이 오답을 입력했을 때 즉시 틀린 사실과 다음 행동을 알 수 있게 합니다.

## 확인된 문제

- 기존 입력 폼은 입력창과 확인 버튼을 같은 줄에 두어 720px 이하 화면에서 입력창이 버튼 폭만큼 줄어들었습니다.
- 1·2번째 오답은 `feedbackMessage`만 변경되고 팝업은 열리지 않아, 학생이 화면 아래의 작은 문구를 놓칠 수 있었습니다.

## 구현 내용

- `src/styles/wordSpelling.css`를 추가해 철자 입력 폼을 전체 너비로 유지했습니다.
- 데스크톱에서는 입력창이 남은 공간을 모두 사용하고 `입력 확인` 버튼은 약 5.6~7rem 폭으로 제한했습니다.
- 720px 이하에서는 입력창을 한 줄 전체로 먼저 배치하고 확인 버튼을 아래에 작게 배치했습니다.
- 첫 번째·두 번째 오답 제출마다 피드백 모달을 표시합니다.
- 모달에는 다음 문구와 선택지를 표시합니다.
  - `아쉽지만 틀렸습니다.`
  - `다시 시도해 볼까요?`
  - `힌트를 하나 더 열어볼까요?`
  - `다시 시도하기`
  - `힌트 하나 더 열기`
- `다시 시도하기`는 오답 입력을 비우고 입력창에 포커스를 되돌립니다.
- `힌트 하나 더 열기`는 기존 힌트 계단을 한 단계 진행하고 입력창으로 돌아갑니다.
- 세 번째 오답은 기존 점수·시도 규칙을 유지하면서 완료 결과 모달을 표시합니다.
- 결과 모달과 오답 모달 모두 배경 스크롤 잠금과 포커스 이동을 유지합니다.

## 실사용 확인

로컬 production preview에서 `도촌초등학교(YBM_최) → 김홍년 → 5학년 7단원`을 선택해 확인했습니다.

- 데스크톱 1280px: 입력창 `933.6px`, 확인 버튼 `89.6px`
- 모바일 360px: 입력창 `265.6px`, 확인 버튼 `89.6px`, 입력창과 버튼은 세로 배치
- 첫 오답: 오답 피드백 모달 표시
- `힌트 하나 더 열기`: 모달 닫힘, 힌트 단계 증가, 입력창 복귀
- 두 번째 오답: 오답 피드백 모달 재표시
- 세 번째 오답: 결과·진행 상황 모달 표시
