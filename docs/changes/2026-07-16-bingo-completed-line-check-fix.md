# 2026-07-16 빙고 특정 단어 체크 실패 수정

## 증상

교사가 호출한 단어가 학생 빙고판에 있고 화면에서도 클릭할 수 있지만, 일부 단어는 클릭 후 `체크 완료`로 바뀌지 않고 Firestore 권한 오류가 발생했습니다.

## 원인

앱은 체크할 때마다 완성된 빙고 줄을 `line-0`, `line-1` 순으로 다시 계산했습니다. Firestore 규칙은 기존 완료 줄 목록 뒤에 새 줄이 추가되는 요청만 허용합니다.

따라서 `line-6`을 먼저 완성한 학생이 나중에 `line-0`을 완성하면 앱은 `["line-0", "line-6"]`을 보냈고, 기존 `["line-6"]`을 앞부분에 유지하지 않았기 때문에 저장이 거절되었습니다.

## 수정

- 기존 Firestore 문서의 완료 줄 순서를 그대로 보존합니다.
- 새로 계산된 완료 줄 중 아직 기록되지 않은 줄만 기존 목록 뒤에 추가합니다.
- 빙고 줄 수, 3빙고 판정, 순위 계산과 잘못된 단어 차단 규칙은 기존 동작을 유지합니다.

## 검증

- 순서 보존 유틸 단위 테스트를 추가했습니다.
- `line-6`을 먼저 완성한 뒤 `line-0`을 완성하는 Firestore 규칙 회귀 테스트를 추가했습니다.
- 기존 번호순 요청이 거절되고 `["line-6", "line-0"]` 요청이 허용되는 것을 확인했습니다.
- 전체 단위 테스트, Firestore 규칙 테스트, 프로덕션 빌드와 브라우저 스모크가 통과했습니다.
- 로컬 브라우저에서 `v1.11.2` 빙고 참여 화면과 업데이트 내역이 정상 표시되고 콘솔 오류·경고가 없음을 확인했습니다.
