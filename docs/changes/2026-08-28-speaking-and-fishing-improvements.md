# 2026-08-28 말하기 판정·단어 낚시 개선

## 배경
말하기 STT가 붙여 쓴 복합어를 다른 단어로 보고, 철자 표기가 발음과 달라진 경우를 오답 처리했습니다.
단어 낚시는 문제 시작 시각과 정답 선택 시각을 이미 기록하고 있었지만 2~4초 구간이 같은 점수였습니다.

## 확인 결과
- 철자 완성 오답 모달은 현재 구현되어 있음을 확인했습니다.
- 첫 번째와 두 번째 오답에는 '아쉽지만 틀렸습니다' 안내와 다시 시도·힌트 선택지가 표시됩니다.
- 세 번째 오답에는 정답과 진행 상황을 보여 주는 결과 모달이 표시됩니다.
- 빈 입력은 시도 횟수로 세지 않고 입력 안내만 표시합니다.

## 구현 내용
### 말하기 연습
- isSpeechMatch에 문장 안의 짧은 단어 묶음을 비교하는 공백 무시 판정을 추가했습니다.
- beef steak와 beefsteak처럼 STT가 복합어 사이에 공백을 넣어도 정답으로 인정합니다.
- ck/k, ph/f, th/t, 묵음 e/gh, c/k/q 등 보수적인 발음 표기 정규화를 추가했습니다.
- 실제 숫자 표기가 들어간 경우에는 기존 숫자 변환을 우선하고, 다른 숫자는 발음 보정으로 통과시키지 않습니다.
- 일반 말하기와 세션 직후 말하기 복습이 같은 공통 판정 함수를 사용하도록 유지했습니다.

### 단어 낚시
- 기존 라운드 측정 시각을 FISHING_ROUND_DURATION_MS와 공유하도록 정리했습니다.
- 정답 점수를 2초 이하 최고 140점, 2~10초 구간 100~140점의 연속 점수로 계산합니다.
- 오답 점수 -30점과 시간 초과 0점 규칙은 유지했습니다.
- 결과 화면의 평균 반응 시간·전체 소요 시간 표시와 리더보드 저장 구조는 유지했습니다.

## 점수 규칙
- 2초 이하 정답: 140점
- 2초 초과 10초 이하 정답: 남은 시간에 비례해 100~140점
- 오답: 30점 감점
- 시간 초과: 0점

- 유사 발음 보정은 숫자 오답까지 허용하지 않도록 제한한 휴리스틱이며, 모든 발음 변형을 보장하지 않습니다.
