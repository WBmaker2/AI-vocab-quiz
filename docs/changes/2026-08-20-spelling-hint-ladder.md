# 2026-08-20 철자 완성 도움 계단형 힌트

## 버전

- 버전: `v1.13.0`
- 날짜: `2026-08-20`
- 대상: 철자 완성 게임

## 목표

학생이 철자를 몰라 멈추지 않도록 필요한 만큼 도움을 받고, 마지막에는 정답을
직접 다시 입력하며 성취감을 느끼도록 개선했습니다.

## 변경 내용

- 기존 단어 길이별 랜덤 마스크를 시작 단서로 그대로 사용합니다.
- `첫 글자 보여줘` 단계에서 숨은 철자를 추가로 공개합니다.
- `한 칸 더 보여줘` 단계에서 내부 철자를 더 공개합니다.
- 마지막 단계에서는 전체 철자를 보여주지만 입력창에 정답을 자동으로 넣지 않고,
  학생이 직접 따라 쓰게 합니다.
- 힌트 사용만으로 입력 기회, `totalAttempts`, `revealedCount`를
  증가시키지 않습니다.
- 힌트를 사용한 뒤에도 학생이 직접 맞히면 기존 시도 횟수별 점수를 적용하고,
  세 번 오답으로 자동 공개되는 기존 리더보드 저장 계약은 그대로 유지합니다.
- 도움 버튼과 입력·다음 문제 버튼에 기존 `gi-pulse` 강조 규칙을
  적용하고, `prefers-reduced-motion` 설정에서는 애니메이션을 줄입니다.
