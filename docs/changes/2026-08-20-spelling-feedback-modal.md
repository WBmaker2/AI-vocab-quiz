# 철자 완성 결과 모달 개선

## 변경 목적

철자 입력을 확인한 뒤 페이지 아래쪽의 결과 영역과 `다음 문제` 버튼을 찾기 위해 스크롤해야 하는 불편을 줄인다.

## 사용자 흐름

```text
철자 입력 -> 입력 확인 -> 결과·진행 상황 모달 -> Enter/Space 또는 버튼 -> 다음 문제
```

## 구현 내용

- `WordSpellingFeedbackModal`을 별도 컴포넌트로 분리했다.
- 입력 결과, 현재 문제 번호, 맞힌 문제 수, 정확도, 점수를 모달에서 함께 보여준다.
- 결과 모달이 열리면 `다음 문제` 버튼으로 포커스를 이동한다.
- 모달이 열린 상태에서 새로 입력한 Enter 또는 Space를 다음 문제 이동 단축키로 처리한다.
- 반복 입력과 조합 입력은 기존처럼 무시한다.
- 마우스·터치 사용자를 위해 모달 안의 버튼을 유지한다.
- 모달이 열린 동안 배경 페이지 스크롤을 잠그고, 좁은 화면에서는 반응형 레이아웃을 사용한다.
- `prefers-reduced-motion` 환경에서는 모달 애니메이션을 끈다.

## 검증 항목

- 정답·오답·정답 공개 후 결과 모달이 표시되는지 확인한다.
- Enter와 Space를 각각 한 번 눌렀을 때 정확히 한 문제만 이동하는지 확인한다.
- 모달의 버튼 클릭으로도 다음 문제와 최종 결과 화면에 이동하는지 확인한다.
- 모바일 폭에서 모달 내용과 버튼이 화면 밖으로 잘리지 않는지 확인한다.
