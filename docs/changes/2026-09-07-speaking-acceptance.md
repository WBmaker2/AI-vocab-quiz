# 말하기 정답 인정 기준 개선

## v1.16.0 · 2026-09-07

- 브라우저 음성 인식 결과를 최대 세 개의 독립된 후보로 보관합니다.
- 첫 후보가 5글자 이상이고 정답과 첫 글자·자음 뼈대·길이가 가깝거나 인접한 두 글자가 뒤바뀐 경우이며, 추가 후보가 정답 전체와 정확히 일치할 때만 제한적으로 정답을 인정합니다.
- `three/tree`, `ship/sheep`, `rice/lice`, `red/led` 같은 보호 혼동쌍과 짧은 단어·다른 숫자·문장 일부 후보는 계속 오답으로 처리합니다.
- 오답 안내는 발음을 단정하지 않고 인식 결과를 알려 준 뒤 다시 듣고 말하도록 안내합니다.

## 확인

- 단위 테스트: 후보 분리, 중간 결과 제외, `appel` → `apple` 보조 인정, 무관 후보 거부, 보호 혼동쌍·숫자·부분 문장 거부를 확인했습니다.
- `npm test`: 175개 통과, Firestore 에뮬레이터 전용 79개 건너뜀. `npm run build`, `git diff --check` 통과.
- ego-browser 모의 `SpeechRecognition`으로 `maxAlternatives=3` 후보 흐름을 실제 `SpeakingQuiz` 화면에서 확인했습니다. `apple` 문제에 `['banana', 'apple']`을 주면 첫 후보 `banana`가 표시되고 점수는 0점으로 유지되며, 재시도하면 `인식 결과: 아직 없음`으로 초기화됩니다.
- 중간 결과 `apple`은 채점하지 않고 점수 0점으로 유지하며, 최종 `['appel', 'apple']`은 화면에 첫 후보 `appel`을 표시하면서 1점으로 인정했습니다.
- 세 번의 `banana` 오답 뒤 완료 화면에서 0/1을 확인하고, 오답 복습에서 `['appel', 'apple']`을 주면 복습 점수 1/1로 인정되는 일반·복습 공통 흐름을 확인했습니다.
- 로컬 확인 주소: [http://127.0.0.1:5173/](http://127.0.0.1:5173/) (현재 개발 서버 실행 중, 배포하지 않음).
- 실제 학생 마이크와 발음 자료를 사용한 검증은 아직 수행하지 않았습니다.
