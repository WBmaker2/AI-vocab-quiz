# 2026-08-12 철자 완성 리더보드 학년 조회 수정

- 버전: `v1.12.3`
- 대상: 교사 리더보드 관리 화면

## 원인

철자 완성 점수는 정상적으로 `spellingLeaderboards`에 저장되어 있었습니다. 다만 교사 리더보드가 로그인 직후 기본값인 `3학년`만 조회하고 있어, 학생이 `6학년` 단어 세트로 기록한 점수가 관리자 화면에서 보이지 않았습니다.

## 수정

- 교사 리더보드에 `조회 학년` 선택을 추가했습니다.
- 기본 조회 학년은 현재 단어 세트 관리 학년으로 시작합니다.
- 조회 학년 변경은 단어 세트 관리 학년과 분리된 상태로 동작합니다.
- 기간 탭은 선택한 조회 학년의 주간·월간·연간·학교 전체 기록을 다시 불러옵니다.

## 운영 확인

- 운영 Firestore에서 도촌초등학교(YBM_최)의 철자 완성 점수가 `6학년` 주간·월간·연간·학교 전체 리더보드에 저장된 것을 확인했습니다.
- 관리자 화면에서 `조회 학년 → 6학년`을 선택하면 해당 점수를 확인할 수 있습니다.
