# 3순위 완료: 예비 인식·약점 보기·받아쓰기

- Safari 예비 인식(실험적): 미지원 브라우저에서 `OfflineSpeechFallback`(녹음→기기 내 Whisper tiny→자체 확인, 점수 미반영). 라이브러리는 고정 버전 CDN 지연 로딩이라 npm 의존성과 감사 이슈가 없고, 모델은 첫 실행 시 1회 내려받기. `offlineSpeech` 유닛 테스트 4건.
- 선생님용 약점 보기: 세션 종료 시 오답 단어 묶음 저장(`wordMissReports`, 세션당 최대 10개), 리더보드 탭에 단어별 집계·학년/활동 필터·새로고침·비우기. Firestore 규칙에 컬렉션 검증 추가 + 규칙 테스트 3건(에뮬레이터 필요).
- 받아쓰기 모드: TTS 듣고 입력·엄격 채점·오답 복습·`gi-pulse` 진행 버튼, 기본 학습 그룹에 진입 버튼 추가. 서버 저장 없는 순수 연습 모드. `dictation` 유닛 테스트 3건.
- 전체 204개 통과, 빌드 정상(모델 청크 지연 로딩 분리 확인).
