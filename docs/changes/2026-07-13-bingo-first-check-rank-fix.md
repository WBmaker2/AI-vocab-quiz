# 2026-07-13 빙고 첫 체크 순위 저장 오류 수정

## 배포 정보

- 버전: `v1.11.1`
- 날짜: `2026-07-13`

## 수정 내용

- 학생 빙고 순위 정규화에서 `null`, 누락값, 빈 문자열을 순위 없음인
  `null`로 유지하도록 수정했습니다.
- 0, 음수, 소수, 유효하지 않은 값은 순위로 쓰지 않고 `null`로
  정규화합니다.
- 학생의 첫 단어 체크 저장 요청도 아직 3빙고가 아닌 경우
  `bingoRank: null`을 유지하므로 기존 Firestore 순위 변경 규칙을
  통과합니다.

## 실제 브라우저 E2E 검증

- 운영 `v1.11.0`의 임시 `QARANK` 세션에서 교사가 `house`(`qa-house`)를
  호출한 뒤 학생이 같은 단어를 누르면 권한 오류가 발생했고, 체크 수는
  0개로 유지됐습니다. 콘솔의 요청 payload에는 `bingoRank`가
  `integerValue: 0`으로 기록됐습니다.
- 로컬 수정 `v1.11.1`을 같은 운영 Firestore 규칙 및 임시 세션에 연결해
  다른 학생으로 `house`를 누르자 1개 체크와 체크 완료 표시가 정상적으로
  나타났으며 콘솔 error/warn은 없었습니다.
- Firestore 저장값도 `markedWordIds: ["qa-house"]`, `bingoRank: null`로
  확인했습니다.
- 검증에 사용한 `QARANK` 세션과 두 학생 문서는 검증 직후 삭제했습니다.

## 회귀 검증

- 순수 함수 테스트로 순위 정규화, 현재 호출 단어만 체크, 중복 체크 차단을
  확인했습니다.
- Firestore 규칙 테스트로 기존 `bingoRank: 0` 첫 체크 요청은 거절되고,
  동일한 `bingoRank: null` 요청은 허용됨을 확인했습니다.
