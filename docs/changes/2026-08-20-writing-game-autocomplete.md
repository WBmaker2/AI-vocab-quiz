# 쓰기 학습 게임 입력 기록 추천 제한

## 변경 목적

철자 완성 게임과 영어 단어 타자 게임에서 이전에 입력한 정답이 브라우저 추천 목록에 나타나면, 학생이 단어를 직접 떠올리고 쓰는 반복 학습을 방해할 수 있습니다.

## 구현 내용

- 두 게임의 정답 입력 form에 `autoComplete="off"`를 적용했습니다.
- 두 게임의 정답 입력창에도 `autoComplete="off"`를 적용했습니다.
- 학생 이름 입력창과 교사·학교 정보 입력창은 자동완성 기능을 유지했습니다.

## 동작 범위와 한계

이 설정은 웹앱이 관리하는 브라우저 자동완성·입력 기록 추천을 제한합니다. 다만 운영체제 또는 휴대전화 키보드 자체의 예측 단어 기능은 브라우저가 별도로 제공하므로 모든 추천을 완전히 차단하지 못할 수 있습니다.
