# 2026-08-12 철자 완성 게임 Enter 키 진행

## 버전

- 버전: `v1.12.2`
- 날짜: `2026-08-12`
- 대상: 철자 완성 게임

## 변경 내용

- 첫 번째 Enter는 기존처럼 입력 내용을 채점합니다.
- 채점 결과가 표시된 뒤 두 번째 Enter는 화면의 `다음 문제` 또는 `결과 보기`
  버튼과 같은 동작을 실행합니다.
- Enter 키를 오래 누르거나 IME 조합 중인 경우에는 다음 문제로 중복 이동하지
  않도록 차단했습니다.
- 다음 문제 버튼에 `aria-keyshortcuts="Enter"`를 추가하고 화면 안내 문구를
  보강했습니다.

## 검증 계획

- 철자 게임의 정답·오답·정답 공개 상태에서 Enter 두 번 입력 확인
- 마지막 문제에서 두 번째 Enter가 `결과 보기`로 연결되는지 확인
- `npm test`, `npm run build`, `npm run test:smoke` 실행
