# 앱 전반 개선 구현 계획 (1~4순위, v1.18.0)

> 작성일: 2026-10-15 / 원칙: 무료 엔진만 사용, VoiceOver 검증 제외, 500줄 규칙 준수, 단계별 md 기록

## 1순위: 바로 체감되는 수정

- STT 오류 맞춤 안내: `speakingMessages.getGuidance`가 브라우저명을 받아 크롬·엣지에서는 망·VPN·확장 점검을, 그 외에는 브라우저 교체 안내. `SpeakingQuiz`에서 `recognition.browserName` 전달. 테스트 추가.
- 단어 그림 카드: 어휘 항목에 `imageUrl` 추가(입력폼·목록 미리보기·Firestore 저장/불러오기·엑셀 입출력), 문제 카드 공용 `WordImage` 표시, 생성 모델로 만든 기본 그림 단어장 8단어 번들 + 교사용 불러오기.

## 2순위: 구조와 사용성

- 500줄 초과 10개 파일 분할: 화면 단위(본 문제·복습·결과 гай드) 또는 탭 단위로 새 컴포넌트 분리. 부모 파일은 조립만 남김.
- `gi-pulse` 확대: 듣기 다시듣기, 짝맞추기·낚시·타자 시작 버튼, 빙고 체크 등 단계별 필수 버튼.

## 3순위: 학습 깊이

- Safari 예비 인식(실험적): 미지원 브라우저에서만 MediaRecorder 녹음 + 지연 로딩 음성 모델 폴백. 기존 흐름과 격리, 명시적 선택 시에만 동작.
- 선생님용 약점 보기: 세션 종료 시 오답 단어 묶음 저장(`wordMissReports`), 교사 리더보드 탭에 단어별 집계.
- 받아쓰기 모드: TTS 듣고 영어 단어 입력, 정규화 비교 채점, 결과·재시도 흐름.

## 4순위: 검증 환경

- `test:rules`(에뮬레이터)·`test:smoke`(브라우저 바이너리) 로컬 실행 복구 시도, 불가 시 CI 게이트 확인과 우회 문서화.

## 릴리스

- 단계별 `docs/changes/` 기록, 완료 시 v1.18.0 일괄 반영 후 커밋·푸시·배포는 별도 승인 후 진행.
