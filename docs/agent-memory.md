# Agent Memory

이 문서는 이 저장소에서 반복적으로 지켜야 하는 사용자 운영 선호를 간단히 남겨두는 메모입니다.
새 스레드에서 작업을 시작할 때 `docs/project-handoff.md`와 함께 확인합니다.

## 사용자 운영 선호

### 2026-04-12

- 주요 개선 사항이 있으면 **배포 전에 문서에 먼저 기록**합니다.
- 배포 전 문서 기록은 기본적으로 아래를 함께 점검합니다.
  - `docs/project-handoff.md`
  - 사용자-visible 변경이면 `src/constants/app.js`의 `APP_UPDATES`
  - 필요하면 관련 plan/spec 문서
- 즉, 앞으로는 **구현 -> 검증 -> 문서 반영 -> 버전업/배포** 순서를 기본 운영 흐름으로 봅니다.
