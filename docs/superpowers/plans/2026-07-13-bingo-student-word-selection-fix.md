# 빙고 학생 단어 선택 오류 수정 계획

작성일: 2026-07-13

## 목표

교사가 빙고 단어를 호출한 뒤 학생이 자기 빙고판의 같은 단어를 눌렀을 때, 첫 클릭부터 Firestore에 정상 저장되고 체크 완료 상태가 실시간으로 표시되게 한다.

## 확인된 장애 경로

1. 학생 참여 문서는 빙고 순위가 아직 없으므로 `bingoRank: null`로 생성된다.
2. 앱의 학생 문서 정규화 과정에서 `Number(null)`이 `0`이 되어 `bingoRank`가 잘못 바뀐다.
3. 학생이 호출된 단어를 클릭하면 저장 요청에 `bingoRank: 0`이 포함된다.
4. Firestore 규칙은 아직 3빙고가 아닌 학생의 순위를 `null`에서 `0`으로 바꾸는 요청을 거절한다.
5. 결과적으로 학생 화면에서 단어 클릭이 체크 완료 상태로 전환되지 않는다.

## 구현 순서

- [x] `null` 또는 빈 값을 실제 순위가 없는 상태로 보존하는 빙고 순위 정규화 함수를 순수 유틸로 분리한다.
- [x] Firebase 학생 문서 정규화가 해당 유틸을 사용하도록 바꾼다.
- [x] 현재 앱이 만드는 `bingoRank: 0` 요청이 규칙에서 거절되는 재현 테스트와, 수정 후 `null` 요청이 허용되는 회귀 테스트를 추가한다.
- [x] 교사 호출 단어와 학생 보드 단어의 일치 판정 및 첫 체크 저장을 단위 테스트로 확인한다.
- [x] 실제 브라우저에서 학생 보드의 호출 단어 클릭, 체크 완료 표시, 콘솔 오류 부재를 확인한다. (운영 Firestore 규칙을 사용한 QARANK 세션에서 `house` 첫 체크와 `bingoRank: null` 저장을 확인)
- [x] 앱 버전과 화면의 업데이트 내역에 수정 내용을 기록한다.

## 완료 기준

- 교사가 호출한 단어가 학생 보드에 있으면 학생이 한 번 눌러 체크할 수 있다.
- 첫 체크 요청이 Firestore 규칙을 통과한다.
- 아직 3빙고가 아닌 학생의 `bingoRank`는 `null`로 유지된다.
- 잘못된 단어 클릭과 이미 체크한 단어의 중복 클릭은 계속 차단된다.
- 전체 테스트, Firestore 규칙 테스트, 빌드, 브라우저 회귀 테스트가 통과한다.
