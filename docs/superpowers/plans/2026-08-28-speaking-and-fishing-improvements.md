# 말하기·단어 낚시 개선 계획

## 목표
말하기 음성 인식의 띄어쓰기와 유사 발음 변형을 정답으로 안전하게 처리하고, 단어 낚시의 빠른 해결 시간을 점수에 반영합니다.

## 확인
- 철자 완성 오답 모달은 현재 첫·두 번째 오답에 표시되고 세 번째 오답은 결과 모달로 이어집니다.
- 말하기 판정은 `isSpeechMatch`의 정확 일치·문장 포함·숫자 변환만 지원합니다.
- 단어 낚시는 이미 라운드 시간을 측정하지만 2초·4초 구간 점수라 속도 차이가 거칩니다.

## 순서
1. 말하기 공백/음성 변형 회귀 테스트 작성
2. 보수적 phrase/phonetic matching 구현
3. 단어 낚시 연속 속도 점수와 테스트 구현
4. 버전·변경 문서 갱신 후 전체 테스트와 빌드 검증

VoiceOver 구현과 검증은 제외합니다.
