# v1.16 릴리스 및 배포 계획

## 범위

- spelling v1.15과 speaking v1.16의 현재 작업 트리 변경을 함께 릴리스합니다.
- Firestore 규칙 변경을 포함하므로 규칙 테스트와 배포를 함께 확인합니다.
- `work/` 감사 증거 로그는 릴리스 커밋에서 제외하고 보존합니다.

## 순서

1. 변경 파일과 버전·배포 설정을 확인하고 비밀 값은 출력하지 않습니다.
2. `npm test`, `npm run test:rules`, `npm run build`, `npm run build:firebase`, `git diff --check`를 실행합니다.
3. 관련 소스·규칙·테스트·변경 문서·계획 문서만 커밋합니다.
4. 현재 브랜치 `codex/typing-leaderboards`를 origin에 푸시하고 CI 결과를 확인합니다.
5. Firebase Hosting과 Firestore 규칙을 배포하고, 가능하면 Vercel Production도 배포합니다.
6. 두 공개 주소의 응답과 버전 표시를 확인할 수 있도록 결과와 링크를 보고합니다.

## 제외

- `main` 병합은 수행하지 않습니다.
- `work/` 증거 로그는 커밋하지 않습니다.
- VoiceOver 구현·검증은 범위에서 제외합니다.
