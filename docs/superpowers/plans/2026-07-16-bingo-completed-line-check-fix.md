# 빙고 특정 단어 체크 실패 수정 계획

작성일: 2026-07-16

## 목표

교사가 호출한 단어가 학생 빙고판에 있을 때, 해당 단어가 새 빙고 줄을 완성하는 위치이더라도 클릭 저장이 항상 Firestore 규칙을 통과하고 `체크 완료`로 표시되게 한다.

## 확인된 장애 경로

1. 학생이 대각선처럼 번호가 뒤쪽인 줄(`line-6`)을 먼저 완성한다.
2. 이후 교사가 가로줄처럼 번호가 앞쪽인 줄(`line-0`)의 마지막 단어를 호출한다.
3. 앱은 완료된 줄 전체를 번호순으로 다시 계산해 `["line-0", "line-6"]`으로 저장한다.
4. Firestore 규칙은 기존 `["line-6"]` 뒤에 새 줄이 추가된 `["line-6", "line-0"]` 형태만 허용한다.
5. 단어 자체는 맞지만 저장 요청이 `permission-denied`로 거절되어 학생 화면이 `체크 완료`로 바뀌지 않는다.

## 구현 순서

- [x] 기존 완료 줄 순서를 보존하고 새로 완성된 줄만 뒤에 추가하는 순수 함수를 `bingoPlayer.js`에 추가한다.
- [x] `markBingoCell`이 재계산된 줄 번호순 배열을 직접 저장하지 않고 순서 보존 결과를 저장하도록 수정한다.
- [x] `line-6`을 먼저 완성한 뒤 `line-0`을 완성하는 재현 단위 테스트를 추가한다.
- [x] 동일한 순서의 실제 Firestore 업데이트가 규칙을 통과하는 통합 테스트를 추가한다.
- [x] 앱 버전을 `v1.11.2`로 올리고 화면의 업데이트 내역과 변경 문서를 기록한다.
- [x] 전체 단위 테스트, Firestore 규칙 테스트, 빌드, 브라우저 실사용 흐름을 검증한다.

## 완료 기준

- 기존 완료 줄의 번호가 새 완료 줄보다 크더라도 클릭 저장이 성공한다.
- 완료 줄 수, `hasBingo`, 빙고 순위 계산은 기존과 동일하게 유지된다.
- 호출되지 않은 단어와 이미 체크한 단어는 계속 저장할 수 없다.
- 화면에서 클릭 직후 체크 수와 `체크 완료` 표시가 갱신된다.
