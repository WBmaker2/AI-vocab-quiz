## 저장 방식

1. 운영 Firestore에서 `도촌초등학교(YBM_최)`에 연결된 실제 활성 교사 계정을 확인합니다.
2. 대상 학년·단원 문서가 이미 있는지 먼저 확인합니다.
3. 기존 문서가 있으면 기존 단어와 새 단어를 합치고, `word + meaning` 중복은 한 번만 남깁니다.
4. 기존 공개 상태를 유지합니다. 신규 세트는 학생이 바로 사용할 수 있도록 공개 상태로 저장합니다.
5. 앱의 교사 단어 세트 일괄 저장 흐름과 동일하게 `vocabularySets` 문서를 원자적 배치로 저장합니다.
6. 저장 후 12개 문서의 학년·단원·출판사·단어 수·공개 상태를 다시 읽어 검증합니다.

## 안전 기준

- 교사 계정이 불명확한 상태에서는 저장하지 않습니다.
- 다른 학년·단원 문서는 수정하지 않습니다.
- 중복 등록 시 기존 단어를 삭제하거나 덮어쓰지 않습니다.
- Firestore 저장 성공과 학생 화면에서 공개 단어 세트가 보이는 것을 별도로 확인합니다.
- 이번 작업이 데이터 등록만으로 완료되면 앱 코드 버전과 화면 업데이트 내역은 변경하지 않습니다. 앱 코드가 변경될 경우에만 별도 버전업·업데이트 기록을 추가합니다.
